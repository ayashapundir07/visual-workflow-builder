# Visual Workflow Builder

A modern, interactive workflow builder application that allows users to create automated flows by connecting draggable blocks. Built with React, TypeScript, and ReactFlow.

## Features

- Drag and drop interface for creating workflows
- Node-based UI with customizable blocks
- Real-time connection validation
- Save and load workflows as JSON
- Modern, responsive design
- Type-safe implementation with TypeScript

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone [repository-url]
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm start
```

The application will be available at `http://localhost:3000`.

## Project Structure

```
src/
  ├── components/       # Reusable UI components
  ├── nodes/           # Custom node components
  ├── store/           # State management
  ├── types/           # TypeScript type definitions
  ├── utils/           # Utility functions
  └── App.tsx          # Main application component
```

## Technologies Used

- React 18
- TypeScript
- ReactFlow for node-based UI
- Material-UI for components
- Zustand for state management
